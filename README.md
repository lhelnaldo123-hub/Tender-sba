# TSCS SBA System

A School-Based Assessment (SBA) system for Tender Sprout Community School. Teachers sign in to record and manage pupil results for each term.

**Live demo:** https://lhelnaldo123-hub.github.io/Tender-sba/

## Features
- Teachers' sign-in
- Term 1, Term 2 and Term 3 views
- Overview dashboard
- Scores entry
- Attendance tracking
- Printable report cards (fits one A4 page)
- Pupil initials shown on the report card when there is no photo
- Handwriting styles and pen colours for report cards and mock slips
- Performance analysis
- Mock exam results and result slips (Basic 9, Mock 1-7)
- Save report cards as PDF, one by one or all together (ZIP)
- Pupil photos page: add one photo per pupil for the whole class
- Subjects page (admin / head): add, remove or rename subjects for all classes or one class
- Term dates: write the Vac date and Open date once for the whole school; they show on every report card
- Fees & arrears: choose a class, write next-term fees and each pupil's arrears; they show on the report cards
- Notices (admin / head): send a message that shows as a bar on top of everyone's screen
- Pupil and teacher management
- Light and dark mode, colours and text size
- Installable on a phone, works offline

## Built with
- HTML, CSS and JavaScript
- Firebase (sign-in and data)
- GitHub Pages hosting

## Files
- `index.html` - the app
- `sw.js` - offline support (change the version number when you upload a new `index.html`)
- `manifest.json` - makes the app installable
- `Screenshot_20261030-124739.png` - school logo and app icon
