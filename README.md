# TSCS SBA System

A School-Based Assessment (SBA) system for Tender Sprout Community School. Teachers sign in to record and manage pupil results for each term.

**Live demo:** https://lhelnaldo123-hub.github.io/Tender-sba/

## Features
- Teachers' sign-in
- Term 1, Term 2 and Term 3 views
- Overview dashboard
- Scores entry
- Attendance tracking
- Printable report cards
- Performance analysis
- Mock exam results
- Pupil and teacher management
- Installable on a phone

## Built with
- HTML, CSS and JavaScript
- GitHub Pages hosting
